# ✦ Inspira FAM Experience

Site desenvolvido para o **Inspira FAM Experience**, evento acadêmico da Faculdade FAM que propõe experiências interativas, conexões, criatividade e novas formas de vivenciar o ambiente universitário.

O projeto foi desenvolvido com foco em **identidade visual, experiência do usuário, responsividade e interação**, buscando transformar a identidade do evento em uma experiência digital.

---

## ✦ Sobre o projeto

O **Inspira FAM Experience** parte da ideia de que uma mesma experiência pode despertar diferentes sensações em cada pessoa.

O site foi criado para apresentar o evento de forma dinâmica e facilitar o acesso às principais informações, como programação, experiências, localização e inscrições.

Além da versão desktop, o projeto foi pensado especialmente para funcionar também em **dispositivos móveis**, mantendo a identidade e as interações do evento.

---

## ✦ O site possui

* Página principal do evento
* Apresentação do conceito do Inspira FAM
* Histórico das edições anteriores

## ✦ Responsividade

O projeto possui adaptações específicas para dispositivos móveis.

Entre os principais ajustes estão:

* reorganização dos conteúdos;
* redução e adaptação da tipografia;
* navegação otimizada;
* cards adaptados para toque;
* mapa reorganizado;
* formulários em uma única coluna;
* controle de overflow horizontal;
* animações adaptadas para telas menores.

## ✦ Páginas

### `index.html`

Página principal do evento.

Apresenta o conceito do Inspira FAM, histórico das edições, experiências, galeria e informações da próxima edição.

### `inscricoes.html`

Página destinada às inscrições.

Possui dois fluxos:

**Visitante** — para quem deseja participar do evento.

**Comercial / Patrocínio** — para empresas, marcas, expositores e possíveis parceiros.

### `mapa.html`

Mapa interativo do evento.

Apresenta diferentes áreas, como:

* Entrada
* Expositores
* Gastronomia
* Atividades
* Networking
* Palco
* Banheiros

Cada espaço pode ser selecionado para visualizar mais informações.
